화면 이름을 몰라도 찾을 수 있는 UI 패턴 도감

원본 사이트의 108개 UI 패턴 구조를 읽고, 내부 개발 플랫폼과 사내 업무앱 제작 문맥에 맞춰 다시 쓴 콘텐츠다. 목표는 복제가 아니라, 코딩하는 사람과 요청하는 사람이 같은 컴포넌트 이름으로 대화하게 만드는 것이다.

패턴명, 분류, 태그 수는 원본 기준으로 맞추고, 설명과 사용 상황, AI 프롬프트, 팁은 한국어 업무앱 문맥으로 새로 작성했다.
